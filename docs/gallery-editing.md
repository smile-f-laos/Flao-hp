# 年度別ギャラリーの更新

- 年度の一覧：`assets/data/gallery-albums.json`（新しい年度を先頭に追加）
- 写真と説明：`assets/data/gallery/2025.json`など、年度ごとのファイル
- 写真：`assets/images/gallery/2025/full/`、一覧用画像：`thumb/`
- 表示：`gallery.html`が年度別の入口、`gallery-2025.html`が年度のアルバム

説明文や並び順は年度別JSONで管理します。`photos`配列の順で表示し、`date`ごとに区切ります。画像の`width`と`height`は拡大画像の寸法です。

日付の横に表示する一言概要は、年度別JSONの`daySummaries`で管理します。日付（例：`2025-12-29`）をキー、概要を値にしてください。概要が未登録の日付は日付と枚数だけを表示します。

2025年度の写真100枚の題名と12日分の一言概要は、ユーザーが写真を1枚ずつ確認して付けた表現に置き換えています。以前の写真からの推測やしおりに基づく仮の説明より、確認済みの表現を優先してください。原資料の連絡先・個人名は掲載していません。

JSONの編集後は、リポジトリのルートで `python scripts/build-gallery.py` を実行し、生成されたHTMLも一緒に保存してください。追加のPythonライブラリは不要です。

2025年度12期は、現在のフォルダにある100ファイルを確認し、使用しない方針の旧写真2枚を除外し、提供された別写真2枚に差し替え、現在は100枚を掲載しています。撮影日時は元画像のDateTimeOriginalを基準に並べています。端末の時計や時差による記録の差は未補正です。元画像は変更せず、公開画像にはEXIF（位置情報を含む）を持たせていません。

写真の説明はユーザーが確認した内容を記載し、個人名・宿泊施設名・詳細な所在地は掲載していません。現在は2025年度・12期のスタディツアーのみを掲載しています。
