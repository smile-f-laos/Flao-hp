# ログイン不要の公開コメント欄

接続先が未設定の間、HPは「準備中」と公式LINEへの案内を表示します。投稿できたように見せる仮フォームは出しません。

## 初回設定

1. 団体の管理に使うGoogleアカウントで、新しいApps Scriptプロジェクトを作ります。既存のF POSなどとは別のプロジェクトを使います。
2. `Code.gs`を貼り付け、所有者がエディタで`setupComments`を実行します。この段階でGoogleの権限許可が必要です。所有者の確認と管理シート作成にのみ使用します。
3. 実行ログに表示される「Smile F LAOS 公開コメント管理」シートを管理者用に保管します。シート自体を一般公開する必要はありません。
4. ウェブアプリとして新しいデプロイを作り、実行ユーザーは自分、アクセスはログインしていないユーザーを含む「全員」にします。
5. デプロイURL（`https://script.google.com/macros/s/.../exec`）を`assets/data/comments.json`の`endpoint`に設定します。
6. ログインしていない状態で、送信→シートの保留行→管理者が公開へ変更→HPの公開表示まで確認します。テスト投稿は確認後に非公開に戻します。

## 日常の管理

- 新しい投稿は「保留」で保存されます。問題がなければシートの「公開状態」を「公開」に変更します。「非公開」にすると一覧に出ません。
- 名前・コメントの公開には、投稿者のチェックによる同意が必要です。
- 公開するのは日付・ニックネーム・本文のみです。メールアドレスやIPアドレスは収集しません。
- 最新50件を表示します。管理シートの下から1000行を対象に公開状態を確認します。
- 1回限りの投稿トークン、同文の短時間の連投防止、1時間300件の上限、文字数制限、簡易的なボット対策があります。大量のスパムには追加対策が必要です。
- Google Apps Scriptの実行上限やGoogle側の埋め込み制限により利用できない場合があります。その場合も公式LINEから連絡できます。

Googleの仕様： https://developers.google.com/apps-script/guides/web
